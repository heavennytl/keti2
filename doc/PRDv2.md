# 《工业模型适配与协同运行系统》PRD（Demo版 v2）

> 基于 v1.0 的优化迭代
> 核心目标：打通一条完整的演示故事线，让评审者能看懂"适配→部署→运行→优化"的全流程价值

---

## 1. 迭代背景

### 1.1 v1.0 的问题

v1.0 实现了 9 个页面的 UI 框架，但存在核心问题：

| 问题 | 表现 | 影响 |
|------|------|------|
| 页面孤立 | 各页面独立展示，无数据联动 | 评审者无法感知系统整体价值 |
| 故事线缺失 | 没有"适配→部署→运行→优化"的完整流程 | 评审者看不懂业务闭环 |
| 交互深度不足 | 页面以静态展示为主，缺乏动态交互 | 评审者无法体验系统能力 |
| 适配中心不突出 | 模型适配中心与其他页面平级，无差异化 | 核心价值被淹没 |

### 1.2 v2 的优化方向

| 优化方向 | 具体措施 | 预期效果 |
|----------|----------|----------|
| **打通故事线** | 页面间通过 URL 参数传递上下文，形成"适配→部署→运行→优化"闭环 | 评审者能跟随故事线走完完整流程 |
| **增强交互** | 一键适配动画、一键部署动画、自动调度动画 | 评审者能直观感受系统能力 |
| **场景联动** | 场景切换时数据联动变化，告警→调度→恢复 | 评审者能体验系统智能调度能力 |
| **驾驶舱收尾** | 调度完成后回到驾驶舱，展示优化后的拓扑图状态 | 评审者能看到前后对比效果 |

## 2. 故事线设计

### 2.1 演示流程

```
驾驶舱（起点）→ 适配中心（一键适配）→ 部署中心（一键部署）→ 监测中心（切换场景）→ 调度中心（自动调度）→ 驾驶舱（收尾）
```

### 2.2 页面间数据传递

| 跳转 | 传递参数 | 触发条件 |
|------|----------|----------|
| 适配中心 → 部署中心 | `?adaptedModel=WeldDetect-v2` | 适配完成，点击"前往部署" |
| 部署中心 → 监测中心 | `?deployedModel=WeldDetect-v2` | 部署完成，点击"前往监测" |
| 监测中心 → 调度中心 | `?alert=焊接车间-A线` | 告警处理，点击"处理"按钮 |
| 调度中心 → 驾驶舱 | 无参数 | 调度完成，点击"返回驾驶舱" |

### 2.3 场景模式联动

| 场景模式 | 监测中心表现 | 调度中心表现 | 驾驶舱表现 |
|----------|-------------|-------------|-----------|
| 正常 | 指标正常，告警少 | 无告警提示 | 节点绿色，数据流正常 |
| 高负载 | GPU 高负载告警，延迟升高 | 告警提示，可自动调度 | 节点黄色，部分告警 |
| 故障 | 节点离线，大量告警 | 紧急告警提示 | 节点红色，离线状态 |

## 3. 页面改造详情

### 3.1 模型适配中心（核心改造）

#### 3.1.1 一键适配功能

在适配任务列表上方增加"一键适配"按钮，点击后自动执行完整的 5 步适配流程：

| 步骤 | 名称 | 模拟内容 | 动画效果 | 时长 |
|------|------|----------|----------|------|
| 1 | 环境检测 | 检测目标产线硬件配置、通信协议、环境条件 | 检测动画 + 日志滚动 | 1.5s |
| 2 | 兼容性评估 | 评估硬件兼容性、协议适配难度、环境差异 | 评分动画 + 日志滚动 | 1.5s |
| 3 | 适配配置 | 自动选择硬件适配器、配置协议参数 | 配置动画 + 日志滚动 | 1.5s |
| 4 | 适配执行 | 执行适配转换、优化模型 | 进度条 + 日志滚动 | 1.5s |
| 5 | 适配验证 | 对比适配前后精度、延迟 | 对比动画 + 日志滚动 | 1.5s |

**适配完成后：**
- 显示适配前后对比数据（精度 72%→94%，延迟 180ms→65ms）
- 显示"前往部署"按钮，跳转到部署中心

#### 3.1.2 适配模式切换

增加"自动适配"和"手动引导适配"两种模式切换：

| 模式 | 说明 | 适用场景 |
|------|------|----------|
| 自动适配 | 一键执行全部 5 步流程 | 快速演示 |
| 手动引导适配 | 分步执行，每步需用户确认 | 详细讲解 |

#### 3.1.3 适配前后对比

适配完成后展示对比数据：

| 指标 | 适配前 | 适配后 | 优化幅度 |
|------|--------|--------|----------|
| 精度 | 72% | 94% | +30.6% |
| 延迟 | 180ms | 65ms | -63.9% |
| 硬件兼容性 | 部分兼容 | 完全兼容 | - |
| 协议适配 | 需手动配置 | 自动适配 | - |

## 5. 技术要点

### 5.1 URL 参数传递

```typescript
// 适配中心 → 部署中心
navigate('/model-deploy?adaptedModel=WeldDetect-v2');

// 部署中心 → 监测中心
navigate('/monitor?deployedModel=WeldDetect-v2');

// 监测中心 → 调度中心
navigate(`/resource-scheduler?alert=${encodeURIComponent('焊接车间-A线')}`);

// 调度中心 → 驾驶舱
navigate('/dashboard');
```

### 5.2 场景模式联动

```typescript
// 场景 Store
const useSceneStore = create((set) => ({
  mode: 'normal', // 'normal' | 'highLoad' | 'fault'
  setMode: (mode) => set({ mode }),
}));

// 监测中心根据场景模式切换数据
const alerts = mode === 'highLoad' ? highLoadAlerts : mode === 'fault' ? faultAlerts : baseAlerts;
const metrics = mode === 'highLoad' ? highLoadMetrics : mode === 'fault' ? faultMetrics : baseMetrics;
```

### 5.3 动画实现

| 动效 | 实现方式 |
|------|----------|
| 步骤流程动画 | 状态机 + CSS Transition |
| 日志滚动 | setInterval 逐行追加 |
| 数字增长动画 | requestAnimationFrame 逐帧更新 |
| 进度条动画 | Ant Design Progress 组件 |

## 7. 风险与应对

| 风险 | 影响 | 应对方案 |
|------|------|----------|
| 动画执行时间过长 | 演示节奏拖沓 | 每步动画控制在 1.5s，总时长不超过 10s |
| URL 参数丢失 | 页面跳转后上下文丢失 | 使用 useSearchParams 读取参数，无参数时正常显示 |
| 场景切换数据不一致 | 页面数据与场景不匹配 | 场景切换时强制刷新页面数据 |
| 浏览器兼容性 | 动画效果不一致 | 使用 CSS Transition 和 Ant Design 标准组件 |
