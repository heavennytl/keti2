### M1：故事线基础（1天）

#### 1.1 URL 参数传递
- [ ] 实现页面间 URL 参数传递机制（useSearchParams）

- [ ] 部署中心 → 监测中心：`?deployedModel=WeldDetect-v2`

- [ ] 创建 useSceneStore（normal / highLoad / fault 三种模式）

## 五、技术要点

### 5.1 URL 参数传递
```typescript
// 适配中心 → 部署中心
navigate('/model-deploy?adaptedModel=WeldDetect-v2');

// 部署中心 → 监测中心
navigate('/monitor?deployedModel=WeldDetect-v2');

// 监测中心 → 调度中心
navigate(`/resource-scheduler?alert=${encodeURIComponent('焊接车间-A线')}`);

// 调度中心 → 驾驶舱
navigate('/dashboard');
```

### 5.2 场景 Store
```typescript
const useSceneStore = create((set) => ({
  mode: 'normal', // 'normal' | 'highLoad' | 'fault'
  setMode: (mode) => set({ mode }),
}));
```

### 5.3 动画实现
| 动效 | 实现方式 |
|------|----------|
| 步骤流程动画 | 状态机 + CSS Transition |
| 日志滚动 | setInterval 逐行追加 |
| 数字增长动画 | requestAnimationFrame 逐帧更新 |
| 进度条动画 | Ant Design Progress 组件 |
