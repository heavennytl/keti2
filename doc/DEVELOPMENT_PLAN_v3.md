# 《工业模型适配与协同运行系统》v3.0 开发计划

> 基于 PRDv3.md 的实施计划
> 核心目标：解决"适配方案不够智能、页面间数据割裂、交互深度不足"三大问题
> 技术栈：React 19 + TypeScript + Vite 8 + Ant Design 5 + Zustand 5 + ECharts 6 + AntV X6 3 + MSW 2 + Framer Motion 12

---

## 一、版本关系说明

| 版本 | 对应文档 | 状态 | 说明 |
|------|----------|------|------|
| v1.0 | PRDv1.md | ✅ 已实现（约 50%） | 9 个页面的基础 UI 框架 |
| v2.0 | PRDv2.md | ✅ 已实现（约 70%） | 故事线打通、页面联动、一键动画 |
| **v3.0** | **PRDv3.md** | **📝 本次迭代** | **智能适配升级、补齐缺失功能、增强交互深度** |

> 注意：v1.0 和 v2.0 的开发计划在 `DEVELOPMENT_PLAN.md` 中，其中约 50% 的任务尚未完成。
> 本计划（v3.0）将覆盖所有未完成项 + PRDv3 新增需求，按 P0/P1/P2 优先级重新排期。

## 八、开发规范

### 8.1 代码规范
- TypeScript 严格模式（已配置）
- ESLint 统一代码风格（已配置）
- 组件使用函数组件 + Hooks
- 页面组件放在 `pages/` 目录下
- 公共组件放在 `components/` 目录下

### 8.2 命名规范
- 组件文件：PascalCase（如 `CompatibilityMatrix.tsx`）
- 工具函数：camelCase（如 `generateRecommendations.ts`）
- 类型定义：PascalCase（如 `AdaptRecommendation`）
- Store：camelCase + Store 后缀（如 `useDashboardStore`）

### 8.3 Git 提交规范
- `feat:` 新功能
- `fix:` Bug 修复
- `docs:` 文档更新
- `refactor:` 重构
- `style:` 样式调整
- `chore:` 构建/工具链
